# YTDownloader - Private YouTube Video Downloader

A clean, ad-free, privacy-focused desktop application to download YouTube videos in various formats and qualities — from 144p to 4K.

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🔒 **100% Private** | Everything runs locally — no data ever leaves your machine |
| 🚫 **Zero Ads** | No popups, no trackers, no malware risks |
| 🎥 **Full Quality Range** | Download from 144p up to 4K (depending on availability) |
| 🎵 **Multiple Formats** | MP4, WebM, MP3, M4A |
| 👁️ **Preview in Browser** | Watch videos in your default browser before downloading |
| 📊 **Progress Tracking** | Real-time download progress bar |
| 💻 **Standalone .exe** | Single executable file — no Python installation required |
| 🎨 **Dark Theme** | Modern dark UI, easy on the eyes |

## 🚀 Quick Start Guide

### Prerequisites

- Windows 10 or 11 (64-bit)
- Internet connection

### Option 1: Run the Python Script

```bash
# Step 1: Clone the repository
git clone https://github.com/KhanAiDev25/YTDownloader.git
cd YTDownloader

# Step 2: Install dependencies
pip install -r requirements.txt

# Step 3: Run the application
python downloader.py
